# Test Method

## Purpose

The test compared a simple Version 1 prompt with a more controlled Version 2 prompt for each restaurant workflow. The aim was to see whether the improved prompt produced a more complete, usable and responsible draft.

## Method

1. Create one fictional input scenario for each workflow.
2. Run Version 1 and record its output without correcting it.
3. Identify missing fields, unsupported assumptions, unclear formatting and unsafe business actions.
4. Redesign the prompt using role, context, required fields, constraints, missing-information rules and human review.
5. Run Version 2 with the same scenario.
6. Compare the outputs against four criteria: factual grounding, completeness, usability and risk control.

## Data and privacy

All names and scenarios are fictional. No real customer, employee, health, payment or business-confidential data was used.

## Limitations

- Each prompt was tested on one main scenario, so results do not prove performance across every restaurant situation.
- Outputs may vary between AI models and repeated runs.
- No live booking, point-of-sale, inventory, rostering or incident system was connected.
- No real staff timing, accuracy score, customer outcome or financial saving was measured.
- A workplace pilot and management-approved evaluation plan are required before implementation.
